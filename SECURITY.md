# Security policy

## Supported versions

Security fixes are applied to the latest released version.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/FaKL-Code/pt-loader/security/advisories/new)
instead of opening a public issue. Include reproduction steps, affected
versions and the expected impact. You should receive an initial response
within seven days.

Please do not include proprietary game assets or personal data in a report.
