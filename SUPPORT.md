# Support

Choose the channel that matches your request:

- Use [GitHub Discussions](https://github.com/FaKL-Code/pt-loader/discussions)
  for installation help, usage questions, and design conversations.
- Use a structured [bug report](https://github.com/FaKL-Code/pt-loader/issues/new/choose)
  for reproducible defects.
- Use a [private security advisory](https://github.com/FaKL-Code/pt-loader/security/advisories/new)
  for suspected vulnerabilities.

Include the package version, runtime versions, a minimal reproduction, and the
complete error. Parser reports should also include relevant `pt-assets inspect`
output.

Do not attach proprietary game assets to public issues or discussions. Reduce
the problem to a synthetic fixture or provide legal, redistributable evidence.
